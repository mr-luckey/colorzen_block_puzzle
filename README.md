# ColorZen: Block Puzzle

Casual 9×9 drag-and-drop block puzzle built with Flutter — place pieces, clear lines, stay zen.

## Features

- **Classic** — endless scoring with combos & color bonuses
- **Daily Challenge** — same seeded puzzle worldwide each day
- **Zen Mode** — no score, silent reset, relaxed play
- **3 themes** — Midnight Zen, Desi Rangoli, Arctic Ice
- Smooth animations, haptics, Hive autosave, AdMob + Remove Ads IAP

## Run

```bash
flutter pub get
flutter run
```

Package ID: `com.appwaretech.colorzen.puzzle`

## Architecture

BLoC/Cubit + Hive + get_it, matching `SRS.txt`.
